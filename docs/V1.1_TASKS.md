# v1.1 Tasks — 互操作层（全部 ✅ 2026-09-08）

> 计划拆自 ROADMAP v1.1 段，全部完成，138 tests 全绿。

## ✅ T1 — Mission 扩展
- `Mission(home=(lat, lon, alt))`，home 随 `to_dict/from_dict/save/load` 持久化（旧数据无 home 字段兼容 None）
- `Mission.insert_waypoint(seq, ...)` 任意位置插入 + seq 重排
- `Mission.remove_waypoint(seq)`（CLI 现有逻辑上收编）
- `Mission.add_action(after_seq, cmd, param1-4, [lat/lon/alt])`：DO_* 项插到指定航点后，
  默认继承前置航点坐标；cmd 支持 int / "DO_X" / "do_x" / "MAV_CMD_DO_X"
- `Mission.add_camera_trigger(mode="distance"|"time", value, after_seq=0)`
  → DO_SET_CAM_TRIGG_DIST / DO_SET_CAM_TRIGG_INTERVAL

## ✅ T2 — actions.py（新，MAV_CMD 常量 + 映射）
- 常量：NAV_WAYPOINT/NAV_TAKEOFF/NAV_LAND/NAV_RTL/DO_JUMP/DO_CHANGE_SPEED/
  DO_SET_CAM_TRIGG_DIST/DO_SET_CAM_TRIGG_INTERVAL/DO_SET_SERVO/DO_GRIPPER 等
- `command_id(x) -> int|None`：int 透传 / 名匹配（大小写不敏感、接受 MAV_CMD_ 前缀、别名如 takeoff/rtl/trigger_dist）
- `command_name(cmd) -> str`（未知回 "UNKNOWN(n)"）
- `is_action(cmd)`：DO_* → True（NAV_* → False）
- 每命令默认 7 参（param1-4 缺省按常量表补 0）

## ✅ T3 — formats.py（新，WPL + QGC .plan 互操作核心）
- `sniff_format(text)` → "wpl" | "qgcplan" | "mavplan" | None
- `parse_wpl(text)`：`QGC WPL 110/120`；首行 HOME（frame 0）→ mission.home；
  param1→delay、param2→acceptance_radius、param4→yaw、alt 兼容 -9999 → 0
- `to_wpl(mission)`：标准 **11 列**（WPL 110 无 autocontinue 列，最大兼容 QGC/MP）
- `parse_qgc_plan(text)` / `to_qgc_plan(mission)`：plannedHomePosition → home；
  items params[0..6] → delay/acceptance_radius/orbit/yaw/x/y/z；导出带空 geoFence/rallyPoints
- `save_qgc_plan(mission, path)` / `load_mission_file(path)`（按扩展名+内容自动探测）
- 坐标写入保留 7 位小数（±1e-6 无损 round-trip）

## ✅ T4 — CLI 集成（cli.py）
- `mission import <path>`：自动探测 WPL/.plan/native JSON → 覆盖当前任务（保留 home）
- `mission camera --mode distance|time --value N --after SEQ`
- `waypoint action <seq> --command DO_X [-p1..-p4]`：插 DO_*，坐标继承
- `waypoint list`：非导航项加 `[DO_XXX]` 后缀
- `export plan`（QGC .plan JSON）/ `export wpl`（QGC WPL 文本）
